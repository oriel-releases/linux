# Oriel

A new wallpaper, every day. Oriel is a free Linux app that sets a fresh, high-quality Unsplash
photo as your desktop wallpaper every day.

**[Download Oriel for Linux](https://github.com/oriel-releases/linux/releases/latest/download/Oriel.AppImage)** · [Website](https://oriel.akbarjon.uz)

This repository hosts Oriel's releases. Installed copies update themselves from here.

Requires a 64-bit Linux desktop (GNOME, KDE Plasma, Xfce, Cinnamon and more). Make the AppImage
executable and open it. Oriel is in beta.
